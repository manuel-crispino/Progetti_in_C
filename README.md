# 📌 Libreria di Progetti in C 
Ogni cartella ha un progettino che ho creato mentre imparo C.
Ci sono cartelle piu utili e altre no,bensí create a scopo didattico .

Quasi ogni cartella ha un Makefile per automatizzare il processo di build e run e le cartelle piu utili hanno anche un readme file dove spiego nei dettagli il funzionamento e l'avviamneto. 

## 📂 Makefile
Per semplificare la gestione del programma, è stato creato un **Makefile** con i seguenti comandi:

- **Compilazione e avvio**:
  ```bash
  make run
  ```
- **Pulizia dei file generati**:
  ```bash
  make clean
  ```

## 🚀 Esecuzione
Dopo aver eseguito `make run`, il programma verrà assemblato e avviato automaticamente.
