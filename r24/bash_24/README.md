# Bash Script 

## What this project does ? 

<p>
This Script run a bash program so you can see your group user listed without a space and separated with a , 
</p>

## How does it run ? 

<p>Just clone the repository and once into the folder you can run ./script.sh.</p>
<p>You will se the output with the group user your username is on.</p>
<p>If you want to change user you can just write the username instead of the $(whoami).</p>
