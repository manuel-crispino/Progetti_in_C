# PUT NUMBER BASE 

## This project convert any decimal numbers as a string of decimal, hexadecimal, octal or binary.

## How to test it ? 

- clone the repository 

- run the following commands 

```bash
clang -Wall -Wextra -Werror -g main.c

./a.out <insert number> <insert the base>

./a.out 8 01 	#example   

#note: run this command to debug

lldb ./a.out 8 01
```
