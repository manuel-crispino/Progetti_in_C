#	Capitalize function

I have recreated the Capitalize function in C language, as a challange.

with the following rules;
 
- Only while loop possible (switch, for, do while ...forbidden)
- No ternary operators
- Only 25 lines possible inside a function included { }

## You can run the code with the following command : 

```bash
 clang -Wall -Wextra -Werror -g main.c
 lldb ./a-out #to debug	
```
