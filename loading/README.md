# 📌 Loading library 

Questo programma e scritto in C , E una libreria di loading che serve per visualizzare il loading e dare un feedback all utente mentre si stanno scaricato i pacchetti. 

ci sono principalmente 2 librerie di loading base che secondo me sono le piu efficenti e pratiche. 

## 📂 Makefile
Per semplificare la gestione del programma, è stato creato un **Makefile** con i seguenti comandi:

- **Compilazione e avvio**:
  ```bash
  make run
  ```
- **Pulizia dei file generati**:
  ```bash
  make clean
  ```

## 🚀 Esecuzione
Dopo aver eseguito `make run`, il programma verrà assemblato e avviato automaticamente.
